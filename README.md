# Wikipédia Moderna - Tema: Segurança Digital

O objetivo do projeto foi criar uma interface moderna para a Wikipédia. O projeto foi desenvolvido em HTML e CSS puro.

## Sobre o Projeto

Este projeto consiste em uma página de artigo sobre Segurança Digital (Cybersecurity), desenhada com foco em legibilidade, experiência de usuário (UX) e tipografia moderna.

O objetivo principal é demonstrar o poder das recursos modernos do CSS (Grid, Flexbox, Variáveis CSS, Native Dark Mode e Smooth Scroll) sem a necessidade de frameworks externos ou linguagens de script.

## Recursos e Destaques

- Design Moderno: Interface limpa inspirada em portais modernos de documentação técnica e wikis contemporâneas.

- Dark Mode Nativo: Transição automática para o tema escuro baseada nas preferências do sistema do usuário (prefers-color-scheme).

- Sidebar com Índice Fixo: Navegação fluida com links de âncora e rolagem suave (scroll-behavior: smooth).

- Infobox Estilizada: Caixa lateral flutuante no estilo Wikipédia para exibição de dados e resumo rápido do artigo.

- Totalmente Responsivo: Layout flexível com CSS Grid e Media Queries otimizadas para smartphones, tablets e desktops.

## Tecnologias Utilizadas

- **HTML5:** Estrutura semântica (header, main, aside, section, footer).

- **CSS3:**

    - Variáveis CSS (Custom Properties) para gerenciamento de temas.

    - CSS Grid & Flexbox para o layout.

    - Media Queries para suporte a telas menores e Dark Mode.
